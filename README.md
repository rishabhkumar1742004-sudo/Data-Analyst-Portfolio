# 📊 Data Analyst project  — Rishabh kumar 

A collection of **6 end-to-end data analytics projects** built using **Power BI, Python, SQL, and DAX**. Each project includes interactive dashboards, data cleaning scripts, SQL queries, and comprehensive documentation.

---

## 🚀 Projects

### 1. [Superstore Sales Dashboard](./superstore_sales_dashboard/)
> **Tools:** Power BI, DAX | **KPIs:** $2.30M Sales, $286K Profit, 37.87K Quantity
>
> Analyzed retail sales performance across the US — regional strengths, product categories, and seasonal revenue trends.

---

### 2. [Customer Segmentation & RFM Analysis](./Customer%20Segmentation%20Analysis/)
> **Tools:** Power BI, Python, DAX | **KPIs:** £8.91M Revenue, 4,372 Customers, 805K Transactions
>
> Applied RFM (Recency, Frequency, Monetary) analysis to segment customers into actionable groups — Champions, Loyal, At Risk, and Lost.

---

### 3. [Olist E-Commerce Marketplace](./Olist_Cleaned/)
> **Tools:** Power BI, Python, SQL | **KPIs:** R$15.44M Revenue, 98.6K Orders, 4.09⭐ Avg Review
>
> Enterprise-grade dashboard processing 8 relational tables into a Star Schema — covering sales, logistics, sellers, and customer satisfaction across Brazil.

---

### 4. [HR Analytics & Employee Attrition](./HR%20Analytics%20Dashboard/)
> **Tools:** Power BI, Python, SQL, DAX | **KPIs:** 1,470 Employees, 16.12% Attrition Rate, ₹6.50K Avg Salary
>
> Identified key attrition drivers across departments, salary bands, age groups, and education fields with a premium dark-mode neon-glow design.

---

### 5. [Netflix Content Analytics](./Netflix%20Content%20Analytics/)
> **Tools:** Power BI, Python, DAX | **KPIs:** 8,807 Titles, 6,131 Movies, 42 Genres, 121 Countries
>
> Explored Netflix's content library — genre trends, country distributions, YoY release growth, and seasonal patterns with a cinematic dark-mode UI.

---

### 6. [Blinkit Grocery Sales & Marketing Analytics](./Blinkit%20Grocery%20Analytics/)
> **Tools:** Power BI, Python, SQL, DAX | **KPIs:** ₹4.97M Revenue, 5K Orders, 1.97x ROAS, 3.34⭐ CSAT
>
> 4-page dashboard covering business overview, product profitability, delivery logistics, and marketing campaign ROI for quick-commerce analytics.

---

## 🛠️ Tech Stack
| Technology | Usage |
|-----------|-------|
| **Power BI** | Dashboard design, Star Schema modeling, KPI cards, interactive visuals |
| **Python** | Data cleaning (Pandas), ETL pipelines, background generation (Pillow) |
| **SQL** | Database schema design, KPI validation, analytical queries |
| **DAX** | Calculated measures (SUMX, DIVIDE, CALCULATE, YoY%), time intelligence |
| **Excel** | Raw data source, lookup tables |
