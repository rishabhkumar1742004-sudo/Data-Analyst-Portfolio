# 📊 Superstore Sales Dashboard

## 📈 Dashboard Preview
> *Screenshots are available in the `Screenshots/` folder.*

## 🎯 Objective
Designed a Power BI dashboard to analyze retail sales performance of a Superstore across the United States, helping stakeholders identify regional strengths, top-performing product categories, and seasonal revenue trends.

## 🛠️ Tools Used
- **Power BI** — Interactive dashboard design, KPI cards, and visual storytelling
- **DAX** — Calculated measures for Sales, Profit, and Quantity KPIs
- **Excel/CSV** — Data source (Sample Superstore dataset)

## 📈 Key KPIs
| KPI | Value |
|-----|-------|
| Total Sales | $2.30M |
| Total Profit | $286.40K |
| Total Quantity | 37.87K |
| Profit Margin | ~12.5% |

## 🧹 Data Cleaning
- Standardized date formats and ensured correct data types for all columns.
- Verified regional mappings and category classifications.

## 📁 Dataset
- **Source:** [Kaggle - Superstore Sales Dataset](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final)
- **Rows:** 9,994
- **Columns:** 21
